# 千年金庫

1026–2026 富豪資料庫。長廊只停有展品的年份。每人有生平、生活、經濟影響同財富去向。

兩把尺並排：

- 折成 2026 年美元
- 身家占當時全球產出

1987 年後的榜首跟 Forbes，並折成 2026 年美元。更早的數字係教學估算，有帳簿先會標明。皇帝同國庫的「國力」另計，唔當私人存款。

## 展廳

長廊之外有十個展廳：起承轉合、全球占比、雙尺排名、錢從何來、錢去咗邊、買到幾多、榜首接力、地圖、生活影響、打對台。

## 本地運行

```bash
npm install
npm run dev
```

開發伺服器預設喺 `http://127.0.0.1:8080`。
